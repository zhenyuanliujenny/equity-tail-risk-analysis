INDEPENDENT TECHNICAL DEMO · PYTHON · NUMPY

Exploring volatility and tail risk

A reproducible, synthetic demonstration of GARCH dynamics, empirical tail measures and one-day GBM Monte Carlo simulation.

All observations and results are synthetic. No real equities, company data, research deliverables or news text are used. This is a newly created personal methods demonstration.

What the demonstration implements

  • Generate three anonymous return series, each with 1,500 daily steps, using a stationary Gaussian GARCH(1,1) recursion.
  • Compute empirical 99% lower-return quantiles (VaR convention) and inclusive-threshold tail means (CVaR / Expected Shortfall convention).
  • Generate 10,000 one-day GBM draws per series using daily sample moments, then compare quantiles and tail means on the same horizon.

GARCH parameters are specified to generate data; they are not estimated. The volatility curve below is known generating volatility, not a fitted estimate or a forecast.

All values are signed daily returns at the 99% confidence convention. Negative values represent losses. CVaR averages returns at or below the sample quantile; it is not a bound on the worst possible loss.

The empirical sample has time-varying generating variance; the GBM comparator uses constant unconditional daily moments. Differences reflect both modeling assumptions and finite simulation/sample variability, not a verified performance advantage.

Reproducibility and limitations

Fixed random seeds are recorded alongside the results. The data generator, report builder and five unit tests are included. No network access or account credentials are needed to run the demo.

  • No GARCH parameter estimation, residual testing or held-out forecast evaluation is implemented.
  • No real-company outcomes, portfolio diversification model, language processing or trading execution is shown.
  • Normal-shock assumptions and the GBM moment approximation are deliberate simplifications. More scenarios do not eliminate model risk.
  • The results demonstrate method behavior, not real asset risk or investment performance.
